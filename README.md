# omababy → omabloat

This repository was renamed. **Omabloat now lives at
[https://github.com/TopGoy333/omabloat](https://github.com/TopGoy333/omabloat).**

That repo has everything this one had — the bloat detector, the guarded cleanup
script, Steam setup, and the Omarchy bar button — in one place.

## Install

```bash
omarchy plugin add https://github.com/TopGoy333/omabloat --enable
```

## Why the change

The bar command is `omabloat`, so the repo is named that too. The old name was
a typo; GitHub keeps this address working and sends visitors to the new repo.
